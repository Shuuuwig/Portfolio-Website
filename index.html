Turn Based RPG

Unity / C#

Turn System Architecture

I designed a modular State Machine to handle turn flow. Priority is calculated using Turn Value (TV = speed / round length).

  • + Lower TV acts sooner in the round
  • + Supports round length modifiers for boss mechanics

Reactive Parrying

A unique mechanic for specific units allowing players to intervene during enemy attacks to negate damage at a resource cost.

Single Multi Targeting

A custom targeting system where players spend resources to select and strike multiple individual units freely.

Procedural Map Generation

Utilizes Perlin Noise and random seeds to create interconnected rooms with no backtracking.

  • + Connections generated via randomized logic
  • + Includes luck-based random event rooms

Party Rank System

Players arrange a 4 party team across front, middle, and back ranks, each providing unique stat bonuses or immunities.

Puzzle Platformer

Unity / C#

Dual Boomerang Mechanics

Features two boomerangs with straight and curved flight paths, used as the primary tools to control and alter surroundings.

Destructible Interaction

Physics Based Environments

Heavily leverages Unity Physics for moving and falling platforms. Progress requires building solutions using environmental props.
